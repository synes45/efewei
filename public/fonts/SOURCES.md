# Local interface fonts

Geist and Geist Mono by Vercel, distributed under the SIL Open Font License 1.1.
Latin and Latin Extended variable WOFF2 subsets are served locally, including Turkish characters.
The site makes no runtime requests to Google Fonts.

Source: Google Fonts CSS API, Geist v5 and Geist Mono v6.
https://fonts.google.com/specimen/Geist
https://fonts.google.com/specimen/Geist+Mono

License sources:
